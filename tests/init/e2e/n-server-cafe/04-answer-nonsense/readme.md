# init/e2e/n-server-cafe/04 — такт 2: обработка ответа — невменяемый ответ

Сценарий плана: **IN-1b** — N серверов кафе + ещё один — такт 2: обработка ответа, корректный результат. Вид теста: e2e (система целиком). Соответствие e2e ↔ node-isolate — `SCENARIOS.md`.

## Сценарий

Пункт IN-1b, ветка «невменяемый ответ». Второй такт с тем же зафиксированным вопросом куратора: пользователь отвечает так, что адреса из ответа не извлечь, или уводит разговор в сторону. Система не должна ни принять такой ответ, ни развалиться: конфликт остаётся, вопрос повторяется (`QA`, лимит 5), рабочий запрос из чата добавления не уходит агентам. Такт заканчивается повторным вопросом.

Вариант A — «ну да».

Вариант B — «ыпаы».

Вариант C — «не знаю, сами разберитесь».

Вариант D — «такой же, как все остальные» (по смыслу ответ, но различия в нём нет).

Вариант E — «а сколько заказов сегодня было на Тверской?» (рабочий запрос внутри чата добавления; только в e2e).

## Стенд

Стенд K — сеть кафе (подробно — `init/README.md`, раздел «Стенд K»): в каждом кафе свой мини-сервер, собранный из одного образа, — одинаковые ОС, службы, теги и структура; кафе различаются только адресом. Серверы кафе cafe-01…cafe-04 (10.30.1.10…10.30.4.10) и сервер офиса office-01 (10.30.0.10) уже добавлены засевом — записи о серверах в памяти системы, логгеры на них не установлены (искусственное состояние: сама система до него не доходит); новый сервер cafe-05 (10.30.5.10) — такой же мини-сервер, добавляется в тесте, логгеры ставятся при подтверждении. Подключение — по SSH через VPN сети; ключ системы `eval_ed25519` принят на всех хостах. Перед тестом — снапшот хостов и состояния системы; после — сброс.

Состояние — как в n-server-cafe/02, шаг 1 (вопрос куратора зафиксирован).

## Вход

Ответ пользователя по варианту. Такт — от ответа до повторного вопроса куратора.

## Цепочка

- Пользователь → куратор: ответ без адреса; куратор не меняет `short-desc` и переспрашивает конкретнее (`QA`, 2-й из 5).
- Вариант E: рабочий запрос в чате добавления не уходит оркестратору и агентам — в журнале нет `delegate`; куратор просит сначала закончить добавление `[предл.]`.
- Признаки разрыва: «ну да», «ыпаы» или «такой же» попали в `short-desc`; `confirmation` без адреса; выдуманный адрес; `deny`; в варианте E выполнен запрос о заказах (запуск агента из чата добавления).

Разрыв цепочки в любом звене — тест не засчитан; где именно он случился, показывают метрики узлов по журналу и парные node-isolate тесты того же кода сценария.

## Ожидаемое поведение

- Конфликт остаётся: куратор `QA` (`conflict`), серверы {10.30.5.10, cafe-01…cafe-04}; `short-desc` не изменён ответом.
- Куратор переспрашивает конкретнее: нужен адрес или место кафе, чтобы вопросы про «кафе на …» уходили на нужный сервер.
- Варианты C и D: куратор объясняет, зачем нужен адрес, и не подставляет его сам.
- Вариант E: рабочий запрос в чате добавления не выполняется `[предл.]` — одна сессия — одно добавление [K §2.3]; эталон: куратор говорит, что сначала нужно закончить добавление, и повторяет вопрос.
- Ошибки: «ну да», «ыпаы» или «такой же» в `short-desc`; `confirmation` без адреса; выдуманный адрес; `deny`; в чате добавления выполнен запрос о заказах на Тверской.

## Эталон

- Цепочка: `QA` (`conflict`), {10.30.5.10, cafe-01…cafe-04}, `short-desc` прежний, `confirmation` не вызвана, `delegate` — 0; вопросов куратора за сессию — два (зафиксированный и повторный).

## Метрики

- Rule-based: `cur-conflict` после ответа (R&B «вопрос задан?» из плана), `e2e-expected-state` (конфликт сохранён, карточка не показана, запусков агентов 0).
- LLM-judge: `judge-cur-question` для повторного вопроса — (1) язык без имён ручек, классов и тегов как идентификаторов; (2) суть: спрошено, чем новый сервер отличается от серверов кафе, — по смыслу сценария это адрес или место кафе; (3) указаны правильные документы: серверы кафе, с которыми совпадает описание, а сервер офиса — нет. Засчитан при всех трёх.
- Узел — `curator/answer-processing/02` (варианты A–D те же).

## Основания

«Переспрашивать куратор может — до 5 вопросов QA; что при отказе пользователя уточнять — не сказано» (`curator-agent.md`); эталон «конфликт остаётся, переспросить» — `[предл.]`; [UC-15].
