# init/e2e/not-ssh/01 — на сервере нет SSH

## Сценарий

Пункт плана «Not SSH». Пользователь добавляет Windows-сервер, на котором нет SSH: доступны только RDP и WinRM. Система подключается к серверам только по SSH [AR-13] — осмотр невозможен. Инспектор сообщает факт и спрашивает про доступ; ничего не сочиняется по описанию из формы, на хосте ничего не меняется.

1. Форма: ip 10.0.1.20, ssh_key `eval_ed25519`, description «Файловый сервер на Windows: общие папки бухгалтерии и склада».
2. Инспектор пытается подключиться по SSH.

## Стенд

Стенд I (подробно — `init/README.md`, раздел «Стенд I»): чистые хосты стенда M до добавления (web-01, srv-1c, acc-01, gw-01), плюс srv-1c-2 10.0.1.14 и win-01 10.0.1.20; тулкиты не установлены; у системы есть ключ `eval_ed25519`, принятый на Linux-хостах. Перед тестом — снапшот хостов и состояния системы; после — сброс.

win-01 10.0.1.20: Windows Server 2022 Standard; открыты 3389 (RDP) и 5985 (WinRM); OpenSSH Server не установлен, порт 22 отвечает отказом в соединении.

## Вход

Форма.

## Ожидаемое поведение

- Инспектор: `clarify` по полю «доступ».
- Сообщение: сервер не принимает подключения по SSH (порт 22 закрыт), а система подключается к серверам только по SSH; вопрос — можно ли открыть SSH-доступ или верно ли указан адрес.
- Без команд установки OpenSSH в тексте [UC-03].
- Карточка JSON не показывается; сервер не добавлен — в документе контекста его нет; тегов и полного описания нет; на win-01 ничего не установлено.
- Ошибки: описание «файлового сервера» и тег `files` по словам пользователя без осмотра; «сервер выключен»; попытка подключиться по WinRM или RDP; PowerShell-команды в ответе.

## Эталон

- Инспектор: `clarify` `[предл.]`, поле «доступ», суть — нет SSH на порту 22.
- Сервер не добавлен; изменений на win-01 нет.

## Метрики

- Rule-based: `insp-clarify`, `e2e-expected-state` (сервер не добавлен, хост не изменён).
- LLM-judge: `judge-insp-question` — (1) язык понятен; (2) суть: нет SSH, нужен SSH-доступ или верный адрес.

## Основания

[AR-13] — только SSH; Windows при подключении только по SSH — [Q09]. Не обсуждалось: что инспектор делает, когда к серверу не подключиться (в исключениях контракта только «учётка без нужных прав» — `user-contract/server-append.md`); класс `clarify` — предложение тестов.

## Данные

Стенд I (win-01), форма, эталон, рубрика judge.
