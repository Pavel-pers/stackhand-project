# inspector/answer-processing/02 — ответ не по делу

## Сценарий

Продолжение inspector/clarify/02: инспектор спросил про postgres в контейнере, пользователь ответил не по вопросу. Инспектор не должен принять решение по тегу сам и не должен отвечать на посторонний вопрос по существу — он возвращает разговор к своему вопросу.

## Контекст инспектора

Как в inspector/clarify/02 (acc-01). История чата:

- Инспектор: «На acc-01 база PostgreSQL работает внутри контейнера микросервисов, отдельной службы СУБД нет. Следить за ней как за отдельной СУБД?»

## Вход

Вариант A — ответ пользователя: «а сколько стоит лицензия 1С на 10 пользователей?».

Вариант B — ответ пользователя: «ну».

## Ожидаемое поведение

- Класс `clarify`, поле — по-прежнему тег db/pg.
- Решение по db/pg не принято молча; набор тегов не изменился.
- Вариант A: о цене лицензий система не отвечает — вне предметной области [UC-03]; коротко сказано, что с этим не поможет, и вопрос повторён.
- Вариант B: вопрос повторён проще, с понятными вариантами ответа (следить отдельно / не следить).
- Ошибки: db/pg добавлен или снят на основании «ну»; ответ про цены 1С; завершение добавления без решения по тегу.

## Эталон

- Класс: `clarify`; поле: теги (db/pg); `tags` без изменений: {host, docker} + открытый кандидат db/pg.

## Метрики

- Rule-based: `insp-clarify` — класс `clarify`, вопрос по ожидаемому полю; вопросов по полям, которые заполняются из осмотра, нет.
- LLM-judge: `judge-insp-question` — (1) язык понятен пользователю: нет имён источников, ручек, шаблонов, классов, `unsupported:*`; имя тега допустимо, если вопрос понятен и без знания модели тегов [UC-08]; (2) суть донесена верно — спрошено именно то, чего не хватает для поля. Тест засчитан при обоих.

## Основания

Не обсуждалось: что делает инспектор, если пользователь отвечает не по делу или отказывается отвечать (`architecture/inspector-agent.md`, `user-contract/clarify.md` — «сколько раундов уточнений допустимо»). Эталон «не принимать, переспросить» — предложение тестов `[предл.]`. «Вне предметной области — не отвечаем» — [UC-03].

## Данные

Контекст inspector/clarify/02, история чата, ответы вариантов A и B, эталон.
