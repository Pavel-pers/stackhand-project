# inspector/answer-processing/02 — ответ не по делу

## Сценарий

Продолжение inspector/clarify/02: инспектор спросил про postgres в контейнере, пользователь ответил не по вопросу. Инспектор не должен принять решение по тегу сам и не должен отвечать на посторонний вопрос по существу — он возвращает разговор к своему вопросу (лимит `ask-user` ≤ 10 [AR-32]).

## Контекст инспектора

Как в inspector/clarify/02 (acc-01). История чата:

- Инспектор (`ask-user`): «На acc-01 база PostgreSQL работает внутри контейнера микросервисов, отдельной службы СУБД нет. Следить за ней как за отдельной СУБД?»

Остаток лимитов: `ask-user` — 9 из 10.

## Вход

Вариант A — ответ пользователя: «а сколько стоит лицензия 1С на 10 пользователей?».

Вариант B — ответ пользователя: «ну».

## Ожидаемое поведение

- `ask-user` (`clarify`), поле — по-прежнему тег db/pg; `submit` не вызван.
- Решение по db/pg не принято молча; набор тегов не изменился.
- Вариант A: о цене лицензий система не отвечает — вне предметной области [UC-03]; коротко сказано, что с этим не поможет, и вопрос повторён.
- Вариант B: вопрос повторён проще, с понятными вариантами ответа (следить отдельно / не следить).
- Ошибки: db/pg добавлен или снят на основании «ну»; ответ про цены 1С; `submit` без решения по тегу.

## Эталон

- Тулза: `ask-user`; поле: теги (db/pg); `tags` без изменений: {host, docker} + открытый кандидат db/pg.

## Метрики

- Rule-based: `insp-clarify` — тулза `ask-user` (класс `clarify`), вопрос по ожидаемому полю; вопросов по полям, которые заполняются из осмотра, нет; `submit` до ответа не вызван.
- LLM-judge: `judge-insp-question` — (1) язык понятен пользователю: нет имён ручек, классов, `unsupported:*`; имя тега допустимо, если вопрос понятен и без знания модели тегов [UC-08]; (2) суть донесена верно — спрошено именно то, чего не хватает для поля. Тест засчитан при обоих.

## Основания

Не обсуждалось: что делает инспектор, если пользователь отвечает не по делу (`inspector-agent.md`, `user-contract/clarify.md`). Эталон «не принимать, переспросить» — `[предл.]`; [UC-03]; лимит вопросов — [AR-32].

## Данные

Контекст inspector/clarify/02, история чата, ответы вариантов A и B, эталон.
