# inspector/answer-processing/01 — ответ пользователя учтён, остальное не изменилось

Сценарий плана: **IN-2b** — Серверы 1С и сайт — вопрос задать нужно: такты «вопрос» и «обработка ответа». Вид теста: node-isolate. Соответствие e2e ↔ node-isolate — `SCENARIOS.md`.

## Сценарий

Пункт IN-2b, такт «обработка ответа» (продолжение inspector/clarify/01): инспектор спросил про место бэкапов, пользователь ответил. Проверяется обработка ответа: поле заполнено по ответу, остальные поля как были, вопрос не повторяется, артефакт сдан.

## Контекст инспектора

Как в inspector/clarify/01 (форма с /backup, результаты ручек с сетевым томом /mnt/nas/pg). История чата (зафиксирована в тесте):

- Инспектор (`ask-user`): «В описании бэкап хранится в /backup, но такого каталога на сервере нет; ночное задание сохраняет дампы в /mnt/nas/pg. Это и есть место бэкапов?»

Остаток лимитов: `ask-user` — 9 из 10.

## Вход

Ответ пользователя: «Да, /mnt/nas/pg — это смонтированный NAS, туда и складываем».

## Ожидаемое поведение

- `submit` (`filled`).
- `tags-full-desc` host: пути бэкапов — /mnt/nas/pg (сетевое хранилище nas-01); задание бэкапа указано с этим путём; `full-desc` — бэкап на NAS.
- Остальные поля совпадают с эталоном inspector/filled/01, кроме тома /backup (его нет) и сетевого тома /mnt/nas/pg (он есть): теги, ИБ, порты, версии не изменились.
- Повторного вопроса о пути нет; новых вопросов нет; повторный осмотр не требуется [Q43].
- Ошибки: в описании остался /backup; ответ записан дословно вместо пути; изменены поля, которых ответ не касался; ещё один `ask-user`.

## Эталон

- Тулза: `submit`; пути бэкапов = /mnt/nas/pg; `tags` = {host, 1c/cluster, db/pg, web/apache}; прочие поля — по чек-листу inspector/filled/01 с заменой тома /backup на сетевой том /mnt/nas/pg.

## Метрики

- Rule-based: `insp-fields` (поле по ответу, остальные без изменений), `insp-clarify` (повторного вопроса нет).

## Основания

«Описание заполняется после ответа» [K §2.2]; ответы пользователя — в описание [UC-15]. Повторный осмотр внутри сессии — [Q43].

## Данные

Контекст inspector/clarify/01, история чата, ответ пользователя, эталон полей.
