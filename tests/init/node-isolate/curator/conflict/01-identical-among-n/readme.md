# curator/conflict/01 — описание совпадает с одним из N серверов

## Сценарий

Добавляется srv-1c-2 — копия баз для франчайзи, но пользователь описал его теми же словами, что и рабочий сервер 1С. Среди четырёх серверов куратор должен найти именно srv-1c и спросить, чем серверы отличаются. acc-01 тоже упоминает postgres, но описывает другое — его в конфликт включать нельзя.

## Контекст куратора

Описание из формы для 10.0.1.14: «Сервер 1С: Бухгалтерия и ЗУП на PostgreSQL».

Краткие описания уже добавленных серверов (стенд M) — вход куратора [UC-15]:

| Название | ip | Теги | Краткое описание |
|---|---|---|---|
| web-01 | 10.0.1.11 | host, web/nginx, db/mysql, unsupported:provider-hv | Публичный сайт компании на VPS у хостинг-провайдера: nginx, PHP, MariaDB; раз в час забирает прайс из 1С |
| srv-1c | 10.0.1.12 | host, 1c/cluster, db/pg, web/apache | Сервер 1С: Бухгалтерия и ЗУП на PostgreSQL, около 12 пользователей; публикует данные 1С для обмена с сайтом; ночной бэкап баз |
| acc-01 | 10.0.1.13 | host, docker | Микросервисы бухгалтерии в Docker: сверка с контрагентами и распознавание первичных документов на GPU; redis и postgres в контейнерах |
| gw-01 | 10.0.1.1 | host | Шлюз офиса: WireGuard-туннели до склада и до VPS сайта; склад работает в 1С через туннель |

Удалённых серверов и «прошлых описаний» нет — с ними куратор не сверяет [UC-10]. Видит ли куратор полное описание, собранное инспектором, — не обсуждалось; в node-isolate тестах куратора его нет.

## Вход

Описание из формы и краткие описания четырёх серверов.

## Ожидаемое поведение

- Класс `conflict`, серверы — {10.0.1.14 (новый), srv-1c}.
- Вопрос: новый сервер описан так же, как srv-1c (10.0.1.12), — чем они отличаются? Пример: «Сервер 10.0.1.14 описан так же, как srv-1c (10.0.1.12): „Сервер 1С: Бухгалтерия и ЗУП на PostgreSQL“. Чем они отличаются?»
- Описание srv-1c не меняется.
- Ошибки: `consistent`; в конфликт включён acc-01 или web-01; вопрос без указания, с каким сервером совпадение; куратор сам придумал отличие («видимо, резервный»).

## Эталон

- Класс: `conflict`; серверы: {10.0.1.14, srv-1c}.
- Суть вопроса: чем 10.0.1.14 отличается от srv-1c.

## Метрики

- Rule-based: `cur-conflict` — класс совпадает с эталоном; при `conflict` — набор серверов совпадает с эталонным.
- LLM-judge: `judge-cur-question` — (1) язык понятен пользователю, без внутрисистемных терминов; (2) суть донесена верно — спрошено, чем серверы отличаются; (3) указаны правильные документы — именно те серверы и описания, между которыми конфликт. Тест засчитан при всех трёх.

## Основания

Пример пользователя — одинаковые краткие описания [UC-15]; формулировка вопроса — [K §2.2]; исключение «конфликт описаний» [UC-17].

## Данные

Описание из формы, краткие описания стенда M, эталонный набор серверов, рубрика judge.
