# curator/deny/01 — замечание требует смены тегов: явный отказ

Сценарий плана: **IN-4** — Перезапись краткого описания сервера куратором после возврата инспектора — замечания пользователя; просьбы вне границ — явный отказ. Вид теста: node-isolate. Соответствие e2e ↔ node-isolate — `SCENARIOS.md`.

## Сценарий

Пункт IN-4, ветка «просьбы вне границ»: на шаге подтверждения пользователь просит изменить теги. Теги пользователь не правит [UC-21]; если ответы требуют смены тегов — явный отказ куратора тулзой `deny` [UC-19]. Куратор не правит теги сам и не делает вид, что изменил.

Остаток: QA 5, confirmation 2.

## Вход

Вариант A — «уберите тег web, апач там не нужен, и добавьте тег backup».

Вариант B — «это не сервер 1С, а сервер бухгалтерии в Docker — поправьте» (ответ противоречит находкам инспектора: 1С найдена, Docker нет; выполнить его — значит сменить теги).

## Ожидаемое поведение

- `deny(reason)` — терминально: теги назначает система по результатам осмотра, вручную они не меняются [UC-21]; в тексте отказа — почему, и что на этом шаге можно было менять только краткое описание и название. После `deny` система закрывает чат, сервер не добавляется [AR-43] — это проверяет `init/e2e/rewrite-short-desc/02` и `system/chat-limit/03`, не этот тест.
- Теги и поля не изменены; нет имитации («тег убрал»).
- B: куратор не переписывает `short-desc` под «сервер в Docker» — это противоречит осмотру и требует смены тегов.
- Ошибки: `confirmation` с изменёнными тегами; `short-desc` «сервер бухгалтерии в Docker»; `QA` «какие теги поставить?»; отказ без объяснения.

## Эталон

- Тулза: `deny`; `tags` без изменений; `short-desc`, `server-name` без изменений.

## Метрики

- Rule-based: `cur-deny` `[предл.]` — тулза `deny` там, где ожидается, и только там (класса в v0.2 нет — [Q50]).
- LLM-judge `judge-cur-deny` `[предл.]`: (1) причина отказа понятна, без имён ручек и классов; (2) нет имитации выполнения; (3) не обещано, что правка будет сделана позже.

## Основания

[UC-19], [UC-21], [AR-31] — deny терминальна; [AR-43], [UC-35] — после deny чат закрывается, сервер не добавляется.
