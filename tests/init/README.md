## Эталонные описания

Правила сравнения: `tags` — совпадение множеств; полное описание — каждый факт чек-листа присутствует и верен (числа — точно, формулировки — по смыслу), выдуманных фактов нет; поля паспорта — по значению; краткое описание — содержит признаки, перечисленные в тесте; название — не пустое (как формируется, не обсуждалось). Формат полного описания и его связь с паспортом не обсуждались [Q07]; эталоны составлены вручную по стенду [Q19].

## Вход узлов в node-isolate

- Инспектор: поля формы, фикстура инвентаря (результат осмотра), выдержка правил detect [T §3.1, §5], история чата добавления.
- Куратор: описание из формы, краткие описания уже добавленных серверов [UC-15], история чата. Видит ли куратор полное описание, собранное инспектором, — не обсуждалось; в фикстурах его нет.
