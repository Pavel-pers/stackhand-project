# response-parse/03 — агент ответил «вопрос не ко мне»

## Сценарий

Оркестратор по слову «1С» отправил вопрос про импорт прайса агенту srv-1c; тот ответил, что такого задания у него нет. Оркестратор должен по своему контексту (сайт получает выгрузку прайса из 1С) изменить решение и переделегировать задачу агенту web-01, а не сообщать пользователю об ошибке.

## Контекст оркестратора

Документ контекста после инициализации стенда «конфигурация C + VPN-шлюз» (ООО «Тестовая компания», оптовая торговля, офис и склад):

| Сервер | Теги | Сводка (бизнес-уровень) |
|---|---|---|
| srv-1c | linux, 1c, postgresql, critical | 1С:Предприятие 8.3 с PostgreSQL; базы Бухгалтерия (БП 3.0) и ЗУП 3.1; около 12 человек; поддержка — франчайзи «1С-Партнёр»; бэкап — pg_dump ночью в /backup (со слов инженера). Пользователи 1С: Иванова А. — главный бухгалтер, Петров С. — бухгалтер, Сидорова М. — кадры, Козлов Д. — склад (только просмотр), admin — франчайзи |
| web-01 | linux, website, nginx, public | публичный сайт (nginx, PHP, MariaDB); раз в час получает выгрузку прайса из 1С; для офиса не критичен |
| acc-01 | linux, docker, microservices, accounting | микросервисы бухгалтерии в Docker: acc-api, acc-worker, redis, postgres; сверка с контрагентами |
| gw-01 | linux, vpn, wireguard, gateway | шлюз офиса с WireGuard-туннелем до склада (peer warehouse); «склад не видит 1С» — смотреть сюда |

Связи: web-01 → srv-1c (выгрузка прайса раз в час), acc-01 → srv-1c (читает данные 1С), gw-01 → srv-1c (склад работает в 1С через туннель).
Сводка каталога: инвентаризация и паспорт, ресурсы и пики, диски с прогнозом, статус служб, ошибки журналов и входы, учётки с доступом, свежесть бэкапов, сертификаты, планировщик.

## Вход

Запрос пользователя: «прайс на сайте вчерашний — выгрузка из 1С отработала?».

Ответ агента srv-1c: `wrong-addressee`, причина — «на srv-1c нет задания импорта прайса на сайт: в планировщике только ночной pg_dump». О других хостах агент не знает — адресата выбирает оркестратор по своему контексту.

## Ожидаемое поведение

- Тип ответа `delegated`, новый адресат — web-01.
- Задача переформулирована для web-01: последние запуски задания импорта прайса и их результат; команд нет.
- Пользователь не получил ошибку вместо ответа; допустима короткая пометка о смене адресата.
- Ошибки: ответ пользователю «не удалось»; повторная отправка srv-1c; делегирование acc-01 или gw-01.

## Метрики

- Rule-based: `agent-choice-correct`.
- LLM-judge: `judge-D-task-formulation` — задача для web-01 полная и без команд, адресат выбран по связи из контекста.

## Данные

Документ контекста оркестратора, запрос пользователя, ответ агента (как в блоке выше), рубрика judge.
