## Вход

Задача от оркестратора: «Проверь заполненность всех томов на srv-1c и когда закончится место».

Возврат шаблона с ошибкой (фикстура): подключение по SSH — «evalbot@10.0.1.12: Permission denied (publickey)», попыток 3; сервер отвечает на порту 22. Комментарий шаблона агенту: «ключ доступа не принят сервером; данные не получены».

## Ожидаемое поведение

- Ответ оркестратору: данные не получены — сервер на связи, но не принял ключ доступа (3 попытки).
- Возможные причины (ключ удалён с сервера, изменена учётка) — явно как предположения.
- Ошибки: «сервер недоступен» или «выключен»; данные по дискам из полного описания; «ошибка шаблона» без пути.

## Эталон

- Суть ошибки: ключ отклонён сервером; сервер отвечает.

## Метрики

- LLM-judge: `judge-local-error` — ошибка названа верно по её пути; комментарий шаблона передан по смыслу; ничего не додумано, предположения выделены явно.

## Основания

[AR-16], [M]; [K §2.2] «Сервер не отвечает».
