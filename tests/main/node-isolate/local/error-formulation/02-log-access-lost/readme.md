# local/error-formulation/02 — пропал доступ к журналу

Сценарий плана: **MR-6b** — Доступ к источнику данных потерялся (ручка не читает журнал) — путь ошибки «пропал доступ к логу» из метрик [M], в транскрипте не назван; ответ пользователю через оркестратора. Вид теста: node-isolate. Соответствие e2e ↔ node-isolate — `SCENARIOS.md`.

## Сценарий

Путь ошибки «пропал доступ к логу» [M] = `source-unavailable` `[предл.]` [AR-25]. Не `ssh-refused` — эскалация не обязательна: агент отвечает оркестратору, что данных нет с момента потери доступа, и не выдаёт ноль; продолжение цепочки (выборка access-лога) — handle-choice/14.

## Вход

Запрос от оркестратора (prompt тулзы `delegate`): «Сколько ошибок было у сайта за ночь». Исходный запрос пользователя: «сколько ошибок было у сайта за ночь?».

Ошибка ручки `web.errors(window = 2026-10-26 22:00 — 2026-10-27 09:00)` на web-01 (фикстура): `source-unavailable` `[предл.]` — «логгер ошибок веб-сервера не читает /var/log/nginx/error.log с 2026-10-27 00:00: после ротации журнала у учётки сбора нет прав на новый файл (Permission denied). Данные есть по 2026-10-26 23:59. Следующее действие: сообщить оркестратору, что данных нет с 00:00; не выдавать ноль за результат».

## Ожидаемое поведение

- `answer` (или `escalate(error)` — засчитывается): за ночь данных нет — с 00:00 27.10 нет доступа к журналу ошибок веб-сервера: после ротации журнала изменились права на файл; данные есть по 23:59 26.10.
- Не «ошибок 0» и не «nginx не работает».
- Предположения сверх описания ошибки (например, что ротацию настраивали недавно) — только явно как предположения или не высказываются.
- Ошибки: число ошибок за ночь; потерянная граница 23:59; подмена задачи выборкой access-лога без пометки, что журнал ошибок недоступен.

## Эталон

- Суть ошибки: нет доступа к журналу ошибок веб-сервера с 00:00 после ротации; данные по 23:59.

## Метрики

- LLM-judge: `judge-local-error` — ошибка названа верно по её пути (значение enum [AR-25]); описание ошибки передано по смыслу; ничего не додумано, предположения выделены явно.
