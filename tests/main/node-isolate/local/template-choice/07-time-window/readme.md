# local/template-choice/07 — окно до установки сборщиков

## Сценарий

Пункт плана «Template mismatch → Time mismatch» на уровне агента. Шаблон есть, но окно запроса раньше начала данных. Агент выполняет чтение за запрошенное окно — и получает пустой возврат; подменять окно нельзя.

## Контекст агента srv-1c

Полное описание srv-1c (из подтверждённого JSON, снято инспектором 2026-10-08): Ubuntu 22.04.4 LTS; 8 vCPU, 32 ГБ ОЗУ, GPU нет. Тома: / (98 ГБ), /var/lib/postgresql (492 ГБ), /backup (980 ГБ). 1С:Предприятие 8.3.24.1548 в режиме кластера: агент 1540, менеджер 1541, рабочие процессы 1560–1591, RAS 1545; ИБ Buh (Бухгалтерия предприятия 3.0) и ZUP (ЗУП 3.1) в PostgreSQL. PostgreSQL 16 (postgresql@16-main, порт 5432). apache2 — публикация 1С для обмена с сайтом (порт 8080). Планировщик: `0 2 * * * /usr/local/bin/backup_1c.sh` — pg_dump баз в /backup/pg. Подрядчик по 1С — франчайзи «1С-Партнёр». Теги: host, 1c/cluster, db/pg, web/apache.

Выдержка из манифестов тулкитов установленных тегов — то, что агент получает в контекст: по источникам типовые вопросы и ключевые поля, по шаблонам — условия применимости [T §2.6, §4]. Выдержка составлена для теста: точные идентификаторы, `questions` и `key_fields` — по манифестам [Q04]; форма ручек — [Q02]; каталог разовых команд — [Q08]. Данные источников — с 2026-10-08 14:20 (установка тулкитов); ретенция: сырые метрики 7 дней, часовые агрегаты 13 месяцев, события 30 дней [T §2.5]. Все действия — только чтение, подтверждений нет [UC-06], [UC-07].

## Вход

Задача от оркестратора: «Загрузка CPU и памяти на srv-1c за сентябрь 2026». Исходный запрос: «какая была нагрузка на сервер 1С в сентябре?».

## Ожидаемое поведение

- Класс `executed`, ручка `host.metrics`, окно — весь сентябрь 2026.
- Ошибки: `no_template` (шаблон есть, нет данных); молча подменённое окно на октябрь; отказ без чтения с выдуманным объяснением.

## Эталон

- Шаблон: ручка `host.metrics`; окно [2026-09-01 00:00; 2026-09-30 23:59] (+03:00), допуск — границы месяца с учётом пересчёта в UTC.

## Метрики

- Rule-based: `local-template-choice` — выбранный шаблон совпадает с эталоном (до решения [Q02] и [Q08] сравнивается источник для ручки и вид разовой команды); `local-template-args` — обязательные аргументы совпадают с эталоном в допуске (допуски — предложение тестов до [Q18]).

## Основания

[K §2.2] «Нет данных за окно»; [UC-13]. Эталон `executed` — предложение тестов: в классах v0.2 нет вердикта «данных нет без выполнения».

## Данные

Контекст агента (полное описание и выдержка манифестов), задача от оркестратора, эталонный шаблон и аргументы с допусками.
