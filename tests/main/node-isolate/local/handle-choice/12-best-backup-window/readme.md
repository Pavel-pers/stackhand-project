# local/handle-choice/12 — «когда лучше делать бэкапы»: составной запрос

Сценарий плана: **MR-1c** — Получение информации — комплексный вопрос («когда лучше делать бэкапы»: агент смотрит логи нагрузки и выбирает окно). Вид теста: node-isolate. Соответствие e2e ↔ node-isolate — `SCENARIOS.md`.

## Сценарий

Пункт плана MR-1c (комплексный вопрос) на уровне агента: ответа нет ни в описании, ни в одной ручке — агент должен посмотреть профиль нагрузки за несколько суток и выбрать окно с меньшей нагрузкой; текущее время бэкапа — из заданий планировщика (а не из памяти). Цикл из двух ручек [AR-26].

## Вход

Запрос от оркестратора (prompt тулзы `delegate`): «По нагрузке за 7–14 суток найти окна с наименьшей нагрузкой CPU и диска; учесть текущий бэкап в 02:00; предложить окно». Исходный запрос пользователя: «когда лучше делать бэкапы на сервере 1С?». Состав запроса агенту постановкой не задан (`agent-loop-work-orchestration.md`, «Артефакты»); в тестах — prompt тулзы `delegate` плюс исходный запрос пользователя `[предл.]`.

## Ожидаемое поведение

- Ручки: `host.load_profile` (resource = cpu, window 7–14 суток, step = hour) — обязательно; `host.sched_jobs(job = backup_1c.sh)` — обязательно (текущее время и длительность бэкапа по факту) `[предл.]`; допустимо `host.load_profile(resource = disk_io, …)`; затем `answer` с окнами.
- Ошибки: `answer` «ночью» без ручек; только `host.now_resources` (момент не говорит о профиле); `host.load_peaks` за сутки как единственная ручка (одни сутки — не профиль); `escalate(no_template)` (ручки есть, нужно их сочетать).

## Эталон

- Ручки: `host.load_profile` (resource = cpu, window ≥ 7 суток, step = hour) + `host.sched_jobs` (job = backup_1c.sh или без фильтра, window ≥ 3 суток); допустимо `host.load_profile(disk_io)`, `host.load_peaks`.
- Допуски: window профиля 7–14 суток.

## Метрики

- Rule-based: `local-handle-choice` — имя ручки совпадает с эталоном; при цепочке из нескольких ручек за запуск — все обязательные ручки эталона вызваны, лишних (не из допустимых) нет `[предл.]` [Q55]; `local-handle-args` — обязательные параметры совпадают с эталоном точно или в допуске (допуски — предложение тестов до [Q18]).
