# local/handle-choice/10 — неверная подсказка в запросе: агент опирается на свой контекст

Сценарий плана: **MR-1a** — Получение информации — динамика параметра (монитор CPU за последний день). Вид теста: node-isolate. Соответствие e2e ↔ node-isolate — `SCENARIOS.md`.

## Сценарий

Наследник старого template-choice/10. Оркестратор подсказал путь к журналу с опечаткой (ngnix). Ошибки веб-сервера агент берёт ручкой `web.errors`, путь ему не нужен; подсказку с несуществующим путём он не использует и не превращает в «ошибок нет».

Перечень ручек агента — то, что агент видит на шаге «просмотр ручек» [AR-26]: ручки типов A — log-inspect (сводка по имеющимся логам) и B — one-shot (сводка на момент «сейчас») с параметрами [AR-24]. Каталог — предложение тестов до [Q08]: имена и параметры условные, при появлении манифестов заменяются ими; эталон `local-handle-choice` сравнивает имя ручки, `local-handle-args` — обязательные параметры в допуске (допуски — [Q18]). Данные логгеров — с 2026-10-08 14:20 (установка); ретенция: сырые метрики 7 дней, часовые агрегаты 13 месяцев, события 30 дней [T §2.5]. Все ручки только читают, подтверждений нет [UC-06], [UC-07]. Лимит — 20 вызовов ручек A и B на запуск, терминальная `answer`/`escalate` не считается [AR-32]; агент видит остаток лимита; вызов сверх лимита отклоняется с комментарием, 10 таких подряд — система закрывает сессию [AR-43].

Терминальная ручка: `answer(text)` — ответ оркестратору; `escalate(kind: no_template | wrong_addressee | error | ambiguous, text)` — эскалация [AR-31]; виды `error` и `ambiguous` (под запрос подходят несколько ручек, без ответа пользователя не выбрать) — предложение тестов, схема — [Q37].

Ошибки ручек — enum с описанием причин и следующих действий [AR-25] (перечень — предложение тестов до [Q20]):

| Код | Когда | Что ручка подсказывает агенту |
|---|---|---|
| `ssh-refused` | подключение к серверу не удалось после 2 попыток с паузой 5 с внутри ручки [AR-42] (ключ отклонён, порт закрыт, таймаут) — в описании ошибки текст SSH и число попыток | сообщить пользователю через эскалацию оркестратору |
| `no-data-for-period` | в логах нет записей за запрошенное окно — в описании самая ранняя запись | сказать, что данных за окно нет; не подменять окно |
| `invalid-param` | значение параметра не подходит — в описании параметр, допустимые значения, примеры | повторить вызов с исправленным параметром |

| `timeout` `[предл.]` | ручка не уложилась в отведённое время (по умолчанию 30 с [AR-42]) | повторить с меньшим окном или сообщить оркестратору |

Предупреждение — не ошибка: если логгер перестал писать (например, не может читать журнал службы после ротации), ручка возвращает сводку по последнюю запись и предупреждение «источник не обновлялся с …» вместе с результатом (design doc 4.1, 5.4).

Момент получения запроса — 2026-10-27 10:00 (+03:00).

## Вход

Запрос от оркестратора (prompt тулзы `delegate`): «Посчитай ошибки за ночь в логе /var/log/ngnix/error.log». Исходный запрос пользователя: «сколько ошибок у сайта за ночь?». Состав запроса агенту постановкой не задан (`agent-loop-work-orchestration.md`, «Артефакты»); в тестах — prompt тулзы `delegate` плюс исходный запрос пользователя `[предл.]`.

## Ожидаемое поведение

- Ручка `web.errors`, window — ночь; затем `answer`.
- Путь из подсказки в параметры не попал; `host.log_excerpt(path = /var/log/ngnix/error.log)` — ошибка (путь не существует, ответ «журнала нет» ввёл бы в заблуждение).
- Ошибки: `host.log_excerpt` по пути из подсказки и `answer` «ошибок 0» или «журнала нет»; «nginx не работает».

## Эталон

- Ручка: `web.errors`.
- Окно «ночь» `[предл.]`: начало — от 2026-10-26 22:00 до 2026-10-27 00:30, конец — от 06:00 до момента запроса (10:00); засчитывается любое окно в этих границах.

## Метрики

- Rule-based: `local-handle-choice` — имя ручки совпадает с эталоном; при цепочке из нескольких ручек за запуск — все обязательные ручки эталона вызваны, лишних (не из допустимых) нет `[предл.]` [Q55]; `local-handle-args` — обязательные параметры совпадают с эталоном точно или в допуске (допуски — предложение тестов до [Q18]).

## Основания

Запрос с выдуманным путём — ошибка постановки (`judge-orch-task`: «без выдуманных путей» [M]); тест проверяет устойчивость агента.

## Данные

Контекст агента (полное описание, описания по тегам, перечень ручек с параметрами), запрос от оркестратора, эталонная ручка и параметры с допусками.
