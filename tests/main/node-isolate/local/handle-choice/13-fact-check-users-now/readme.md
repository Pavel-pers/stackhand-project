# local/handle-choice/13 — «кто сейчас на сервере»: не из описания

Сценарий плана: **MR-7a** — Fact checking — локальный агент проверяет на сервере, а не отвечает по полному описанию (только node-isolate). Вид теста: node-isolate. Соответствие e2e ↔ node-isolate — `SCENARIOS.md`.

## Сценарий

Пункт плана MR-7a, пример A: в `tags-full-desc` 1c у srv-1c записаны учётки и активные сеансы на момент осмотра инспектором (2026-10-08). На запрос «какие пользователи сейчас на сервере» агент не отвечает по памяти с сервера, а проверяет реальную информацию one-shot.

## Вход

Вариант A — Запрос от оркестратора (prompt тулзы `delegate`): «Кто сейчас подключён к базам 1С (активные сеансы)». Исходный запрос пользователя: «какие пользователи сейчас на сервере 1С?».

Вариант B — Запрос от оркестратора (prompt тулзы `delegate`): «Кто сейчас работает на сервере». Исходный запрос пользователя: «кто сейчас на сервере 1С?». (неясно: сеансы 1С или входы на хост). Состав запроса агенту постановкой не задан (`agent-loop-work-orchestration.md`, «Артефакты»); в тестах — prompt тулзы `delegate` плюс исходный запрос пользователя `[предл.]`.

## Ожидаемое поведение

- A: ручка `1c.now_sessions` (тип B); затем `answer` с текущими сеансами.
- B: `1c.now_sessions` и `host.now_resources`/`host.auth_events(success, сегодня)` — допустимо оба толкования, обязательно хотя бы `1c.now_sessions` `[предл.]` (в описании сервера «пользователи» — пользователи 1С); затем `answer` с оговоркой, что показано.
- Ошибки: `answer` со списком «12 учёток: ivanova, petrov…» из описания без ручки; «активных сеансов 7» (снимок осмотра) как текущее; `1c.sessions_history` вместо момента.

## Эталон

- Ручка: `1c.now_sessions`; параметры — нет. B — дополнительно допустимо `host.auth_events` или `host.now_resources`.

## Метрики

- Rule-based: `local-handle-choice` — имя ручки совпадает с эталоном; при цепочке из нескольких ручек за запуск — все обязательные ручки эталона вызваны, лишних (не из допустимых) нет `[предл.]` [Q55]; `local-handle-args` — обязательные параметры совпадают с эталоном точно или в допуске (допуски — предложение тестов до [Q18]).
