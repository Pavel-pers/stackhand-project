# local/answer-from-return/09 — сводка большого объёма: ответ по итогам, не пересказ

Сценарий плана: **MR-1d** — Читаемость ответа пользователю — не сырые данные тулз, а показательные с комментариями; данные разрозненные, неструктурируемые, большого объёма. Вид теста: node-isolate. Соответствие e2e ↔ node-isolate — `SCENARIOS.md`.

## Сценарий

Пункт MR-1d на уровне агента: сводка журнала регистрации за день — 48 тысяч событий; агент отвечает оркестратору итогами (ошибки, отмены, пики, активные пользователи), не пересказывая список и не теряя ошибок.
