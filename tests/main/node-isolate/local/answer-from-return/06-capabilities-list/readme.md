# local/answer-from-return/06 — перечень возможностей по серверу

Сценарий плана: **MR-8b** — Что умеет модель на конкретном сервере — знания локального агента о своих ручках. Вид теста: node-isolate. Соответствие e2e ↔ node-isolate — `SCENARIOS.md`.

## Сценарий

Пункт плана MR-8b на уровне агента: что умеет модель на конкретном сервере — знания агента о своих ручках, про которые оркестратор не в курсе. Ручки не выполняются: агент перечисляет по перечню ручек своих тегов, о чём можно спросить.

| Код | Когда | Что ручка подсказывает агенту |
|---|---|---|

## Вход

Запрос от оркестратора (prompt тулзы `delegate`): «Перечислить, о чём можно спросить по этому серверу: какие данные собираются и какие проверки доступны». Исходный запрос пользователя: «что можно узнать про сервер 1С?».

## Ожидаемое поведение

- `answer` без вызова ручек A/B; перечень по перечню ручек: нагрузка CPU и памяти — пики, профиль по часам, что грузило сервер; место на томах, рост и прогноз заполнения; какие каталоги занимают место; какие службы падали или перезапускались; кто заходил на сервер и неудачные входы; задания планировщика и их запуски; свежесть файлов бэкапа; сеансы 1С — кто в базах сейчас и история; журнал регистрации 1С — сводка и выборка по пользователю; состояние кластера 1С сейчас; блокировки в PostgreSQL; бэкапы СУБД по её журналам; активность в СУБД сейчас; ошибки и доступность публикации 1С; что грузит сервер прямо сейчас; инвентаризация сейчас; размер любого каталога; выборка из любого журнала по фильтру.
- Отмечено, что всё — только чтение.
- Ничего сверх перечня: ни перезапусков, ни завершения сеансов, ни дашбордов.
- Ошибки: перечень только по host (пропущены 1С, СУБД, публикация); обещание действий вне перечня; выполнение ручек «для примера»; `escalate(no_template)`.

## Эталон

- Терминальная ручка: `answer`; ручки A/B не вызваны (rule-based `[предл.]` — класс ответа агента без выполнения ручек в v0.2 не определён, [Q37]).
- Перечень: все группы перечня ручек srv-1c, без добавлений.

## Метрики

- LLM-judge: `judge-local-answer` в адаптации — ответ опирается только на перечень ручек (вместо сводки); ничего не добавлено.
