## Ожидаемое поведение

- `answer`: самые спокойные окна — 04:00–07:00 (3–4 %) и 23:00–02:00 (5–6 %); 02:00–03:00 — пик до 94 % с высоким дисковым вводом-выводом — это само задание бэкапа (02:00–02:15 по планировщику, 7 из 7 успешно); рабочий день 08:00–19:00 — 35–58 %; предложение — 04:00–05:00 или оставить 02:00 (ночью пользователей нет), на выбор пользователя.
