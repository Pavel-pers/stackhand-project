## Вход

Запрос от оркестратора (prompt тулзы `delegate`): «Измерь скорость интернет-канала до внешнего сервера». Исходный запрос пользователя: «какая скорость интернета у сервера 1С?».

## Ожидаемое поведение

- `escalate(no_template)`, ручки A/B не вызваны.
- Текст эскалации: подходящей ручки нет; перечень того, что можно узнать по серверу, — допустимо (оркестратор возьмёт его в отказ [UC-25]).
- Ошибки: подмена `host.now_resources` или `host.load_profile` как ответом о скорости канала; самодельная команда speedtest, curl, iperf (команд у агента нет [AR-03]); `wrong_addressee` (тема — сам сервер).

## Эталон

- Эскалация: `no_template`.

## Метрики

- Rule-based: `local-no-template` — эскалация `no_template` там, где под запрос нет ни ручки A, ни ручки B, и только там.
