## Вход

Задача от оркестратора: «Кто сейчас подключён к базам 1С (активные сеансы)». Исходный запрос: «склад жалуется, что не может зайти в 1С — кто сейчас сидит в базе?».

## Ожидаемое поведение

- Класс `wrong_addressee`, шаблон не выбран.
- Причина: на gw-01 нет 1С — ни тега, ни упоминания в описании.
- На другой сервер агент не указывает: чужих контекстов у него нет, адресата меняет оркестратор.
- Ошибки: `no_template`; входы по SSH из `host.auth` как «кто подключён»; «сеансов нет».

## Эталон

- Класс: `wrong_addressee`.

## Метрики

- Rule-based: `local-wrong-addressee` — `wrong_addressee` там, где тема запроса не покрыта ни тегами, ни описанием сервера, и только там.
