## Вход

Задача от оркестратора: «Какие контейнеры перезапускались за последние сутки». Исходный запрос: «какие контейнеры перезапускались за сутки?».

## Ожидаемое поведение

- Класс `wrong_addressee`, шаблон не выбран.
- Ошибки: `no_template`; перезапуски служб из `host.services`, выданные за контейнеры; «контейнеров нет» как ответ пользователю.

## Эталон

- Класс: `wrong_addressee`.

## Метрики

- Rule-based: `local-wrong-addressee` — `wrong_addressee` там, где тема запроса не покрыта ни тегами, ни описанием сервера, и только там.
