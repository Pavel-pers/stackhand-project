## Вход

Запрос пользователя: «какие авторизации были на сервере с 1С». Ответ агента в тест не входит — проверяются выбор сервера и запрос агенту (prompt тулзы `delegate`).

## Ожидаемое поведение

- `delegate`, адресат — srv-1c.
- Запрос агенту: успешные и неудачные входы на сервер; период назван явно — по умолчанию разумно «последние сутки».
- Не спутано со входами пользователей в базы 1С.
- Ошибки: запрос без периода; запрос про сеансы 1С; ответ без делегирования.

## Эталон

- Тулза: `delegate`; `delegate_to`: srv-1c; период — назван (значение по умолчанию не обсуждалось, засчитывается любое явное окно).

## Метрики

- Rule-based: `orch-agent-choice` (`delegate_to` совпадает с эталоном), `orch-no-delegation` (ожидается `delegated`, не `answered`).
- LLM-judge: `judge-orch-task` — запрос агенту (prompt тулзы `delegate`) полный: сервер, что узнать, период или момент, параметры из запроса пользователя; без команд; без выдуманных путей и фактов. Засчитан при всех критериях.

## Основания

[AR-23]; «как агент получает период из запроса, если пользователь его не назвал — не обсуждалось» (`architecture/agent-loop-work-orchestration.md`) — эталон требует только явного периода.
