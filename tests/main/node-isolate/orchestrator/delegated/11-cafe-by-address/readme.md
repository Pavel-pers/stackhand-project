# orchestrator/delegated/11 — одинаковые серверы кафе: маршрут по адресу в кратком описании

Сценарий плана: **IN-1b** — N серверов кафе + ещё один — такт 2: обработка ответа, корректный результат. Вид теста: node-isolate. Соответствие e2e ↔ node-isolate — `SCENARIOS.md`.

## Сценарий

Пара к init/e2e/n-server-cafe на уровне узла. У пяти серверов кафе одинаковые теги и роль — различить их оркестратор может только по адресу из краткого описания. Вопрос с адресом должен уйти ровно на тот сервер; вопрос без адреса — стать уточнением со всеми кафе в вариантах, без сервера офиса.

## Вход

Вариант A — «сколько места осталось на сервере кафе в Авиапарке?».

Вариант B — «сколько места осталось на сервере кафе на Покровке?».

Вариант C — «что сейчас грузит сервер кафе у Сокола?».

Вариант D — «сколько места осталось на сервере кафе?» (адрес не назван).

Агент в тесте не участвует — проверяется только оркестратор; транскрипт сессии пуст, счётчики тулз — 0.

## Ожидаемое поведение

- A: `delegate` cafe-05; B: cafe-03; C: cafe-04; запрос — о месте на дисках (A, B) или о текущей нагрузке (C), без адреса как технического параметра.
- D: `ask-user`, ситуация A; варианты — все пять кафе с адресами; office-01 в вариантах нет (роль другая).
- Ошибки: в A–C — уточнение «какое кафе?» при названном адресе; `delegate` другому кафе; в D — `delegate` наугад или office-01 в вариантах.

## Эталон

- A: `delegate_to` cafe-05; B: cafe-03; C: cafe-04.
- D: `ask-user` (`clarify`) A; варианты {cafe-01, cafe-02, cafe-03, cafe-04, cafe-05}.

## Метрики

- Rule-based: `orch-agent-choice` (A–C), `orch-clarify-A` (D).
- LLM-judge: `judge-orch-task` — запрос агенту (prompt тулзы `delegate`) полный: сервер, что узнать, период или момент, параметры из запроса пользователя; без команд; без выдуманных путей и фактов. Засчитан при всех критериях.
- LLM-judge: `judge-orch-question` — (1) язык понятен пользователю: нет имён ручек, источников как идентификаторов, классов, тегов как идентификаторов (теги в скобках рядом с описанием, как в примере контракта [K §2.2], допустимы); (2) суть донесена верно. Засчитан при обоих.

## Основания

[AR-23] — выбор по краткому описанию, тегам и названию: теги у кафе одинаковые, различает только краткое описание; [UC-15] — для этого куратор и добивается адреса. Стенд K — пояснение автора плана 2026-10-27.
