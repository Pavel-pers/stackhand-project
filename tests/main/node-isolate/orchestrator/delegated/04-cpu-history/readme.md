## Вход

Вариант A — «какая была загрузка процессора на сервере 1С за последние сутки?».

Вариант B — «какая загрузка CPU на srv-1c за последний час?».

Вариант C (GPU, допущение тестов) — «как была загружена видеокарта на сервере распознавания документов за сутки?». Ответ агента в тест не входит — проверяются выбор сервера и запрос агенту (prompt тулзы `delegate`).

## Ожидаемое поведение

- `delegate`, вопросов нет.
- A: srv-1c; запрос — загрузка CPU за последние 24 ч (2026-10-26 10:00 — 2026-10-27 10:00): среднее, пики и когда они были.
- B: srv-1c; запрос — загрузка CPU за последний час (09:00–10:00).
- C: acc-01 (краткое описание: распознавание первичных документов на GPU); запрос — загрузка GPU и память видеокарты за последние 24 ч.
- Ошибки: `ask-user`; период потерян или заменён («за неделю»); C — `delegate` srv-1c.

## Эталон

- A, B: `delegate_to` srv-1c; C: `delegate_to` acc-01; период в запросе — 24 ч / 1 ч.

## Метрики

- Rule-based: `orch-agent-choice` (`delegate_to` совпадает с эталоном), `orch-no-delegation` (ожидается `delegated`, не `answered`).
- LLM-judge: `judge-orch-task` — запрос агенту (prompt тулзы `delegate`) полный: сервер, что узнать, период или момент, параметры из запроса пользователя; без команд; без выдуманных путей и фактов. Засчитан при всех критериях.

## Основания

[AR-23]; критерии постановки задачи [M]. Вариант C считается сразу: маршрут и запрос не зависят от того, собираются ли метрики GPU (это решается на стороне агента — local/handle-choice/09).

Документ контекста, запрос, эталонный адресат и содержание запроса агенту, рубрика judge.
