## Вход

Запрос пользователя: «сравни свободное место на srv-1c и на сервере сайта». Ответ агента в тест не входит — проверяются выбор сервера и запрос агенту (prompt тулзы `delegate`).

## Ожидаемое поведение

- `delegate` одному из двух серверов (srv-1c или web-01) с запросом о свободном месте на томах; второй запуск — после ответа первого (вне этого теста — `report/16`).
- Ошибки: `reject` «по одному серверу за раз»; `ask-user` «какой сервер?» (оба названы); `delegate` acc-01.

## Эталон

- Тулза: `delegate`; `delegate_to` ∈ {srv-1c, web-01}.

## Метрики

- Rule-based: `orch-agent-choice` (`delegate_to` совпадает с эталоном), `orch-no-delegation` (ожидается `delegated`, не `answered`).
- LLM-judge: `judge-orch-task` — запрос агенту (prompt тулзы `delegate`) полный: сервер, что узнать, период или момент, параметры из запроса пользователя; без команд; без выдуманных путей и фактов. Засчитан при всех критериях.
