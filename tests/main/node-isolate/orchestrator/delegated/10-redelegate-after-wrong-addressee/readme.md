# orchestrator/delegated/10 — переделегирование после «вопрос не ко мне»

## Сценарий

Наследник старого response-parse/03. Оркестратор отправил вопрос о сеансах 1С шлюзу gw-01 (в его описании есть «склад работает в 1С через туннель»); агент шлюза ответил `wrong_addressee`. Оркестратор должен по своему контексту выбрать srv-1c и переформулировать задачу; пользователь перенаправления не видит [UC-16].

## Контекст оркестратора

Документ контекста стенда M (ООО «Тестовая компания», оптовая торговля: офис, склад, сайт). Четыре сервера добавлены через форму 2026-10-08; у оркестратора по каждому — ip, теги и краткое описание из подтверждённого JSON, полного описания нет [UC-04]. Название сервера в документе контекста — `[предл.]`; в тестах это имя хоста.

| Название | ip | Теги | Краткое описание |
|---|---|---|---|
| web-01 | 10.0.1.11 | host, web/nginx, db/mysql, unsupported:provider-hv | Публичный сайт компании на VPS у хостинг-провайдера: nginx, PHP, MariaDB; раз в час забирает прайс из 1С |
| srv-1c | 10.0.1.12 | host, 1c/cluster, db/pg, web/apache | Сервер 1С: Бухгалтерия и ЗУП на PostgreSQL, около 12 пользователей; публикует данные 1С для обмена с сайтом; ночной бэкап баз |
| acc-01 | 10.0.1.13 | host, docker | Микросервисы бухгалтерии в Docker: сверка с контрагентами и распознавание первичных документов на GPU; redis и postgres в контейнерах |
| gw-01 | 10.0.1.1 | host | Шлюз офиса: WireGuard-туннели до склада и до VPS сайта; склад работает в 1С через туннель |

Плюс инструкции оркестратора и история текущей сессии [K §2.3]. Момент запроса — вторник 2026-10-27, 10:00 (+03:00), если в тесте не сказано иное.

## Вход

Запрос пользователя: «склад жалуется, что не может зайти в 1С — кто сейчас сидит в базе?».

Первое делегирование: gw-01 — «Кто сейчас подключён к базам 1С (активные сеансы)».

Ответ агента gw-01: класс `wrong_addressee`, причина — «на gw-01 нет 1С: тема не покрыта ни тегами, ни описанием сервера». О других серверах агент не знает — адресата выбирает оркестратор.

## Ожидаемое поведение

- Класс `delegated`, новый адресат — srv-1c.
- Задача: кто сейчас подключён к базам 1С (активные сеансы), с указанием, что вопрос связан с жалобой склада; без команд.
- Пользователь не получил ошибку; допустима короткая пометка, что вопрос передан серверу 1С.
- Ошибки: ответ «не удалось»; повторная отправка gw-01; делегирование web-01 или acc-01; вывод «склад не подключён» из ответа шлюза.

## Эталон

- Класс: `delegated`; `delegate_to`: srv-1c.

## Метрики

- Rule-based: `orch-agent-choice` (адресат после `wrong_addressee`).
- LLM-judge: `judge-orch-task` — задача агенту полная: сервер, что узнать, период или момент, параметры из запроса; без команд; без выдуманных путей и фактов. Засчитан при всех критериях.

## Основания

«Если нужного тега на сервере нет, агент отвечает отказом, а оркестратор перенаправляет запрос» [T §2.6]; [UC-16]. Не обсуждалось: лимит повторных делегаций (`architecture/orchestrator-agent.md`).

## Данные

Документ контекста стенда M, запрос, первое делегирование, ответ агента, эталон, рубрика judge.
