# orchestrator/delegated/08 — «что можно узнать про сервер 1С?»

## Сценарий

Сторона «Local side» пункта плана «What you can». Что можно спросить о конкретном сервере, зависит от тулкитов его тегов — это знает агент сервера [T §2.6]. Оркестратор передаёт вопрос агенту srv-1c.

## Контекст оркестратора

Документ контекста стенда M (ООО «Тестовая компания», оптовая торговля: офис, склад, сайт). Четыре сервера добавлены через форму 2026-10-08; у оркестратора по каждому — ip, теги и краткое описание из подтверждённого JSON, полного описания нет [UC-04]. Название сервера в документе контекста — `[предл.]`; в тестах это имя хоста.

| Название | ip | Теги | Краткое описание |
|---|---|---|---|
| web-01 | 10.0.1.11 | host, web/nginx, db/mysql, unsupported:provider-hv | Публичный сайт компании на VPS у хостинг-провайдера: nginx, PHP, MariaDB; раз в час забирает прайс из 1С |
| srv-1c | 10.0.1.12 | host, 1c/cluster, db/pg, web/apache | Сервер 1С: Бухгалтерия и ЗУП на PostgreSQL, около 12 пользователей; публикует данные 1С для обмена с сайтом; ночной бэкап баз |
| acc-01 | 10.0.1.13 | host, docker | Микросервисы бухгалтерии в Docker: сверка с контрагентами и распознавание первичных документов на GPU; redis и postgres в контейнерах |
| gw-01 | 10.0.1.1 | host | Шлюз офиса: WireGuard-туннели до склада и до VPS сайта; склад работает в 1С через туннель |

Плюс инструкции оркестратора и история текущей сессии [K §2.3]. Момент запроса — вторник 2026-10-27, 10:00 (+03:00), если в тесте не сказано иное.

## Вход

Запрос пользователя: «что можно узнать про сервер 1С?». Ответ агента в тест не входит — проверяются выбор агента и постановка задачи.

## Ожидаемое поведение

- Класс `delegated`, адресат — srv-1c.
- Задача: перечень того, о чём можно спросить по этому серверу — какие данные собираются и какие проверки доступны.
- Ошибки: общий ответ «что ты умеешь» без делегирования; делегирование всем агентам.

## Эталон

- Класс: `delegated` `[предл.]`; `delegate_to`: srv-1c.

## Метрики

- Rule-based: `orch-agent-choice` (`delegate_to` совпадает с эталоном), `orch-no-delegation` (ожидается `delegated`, не `answered`).
- LLM-judge: `judge-orch-task` — задача агенту полная: сервер, что узнать, период или момент, параметры из запроса; без команд; без выдуманных путей и фактов. Засчитан при всех критериях.

## Основания

Разведение «orchestrator side / local side» — из плана. Не обсуждалось: вопросы о возможностях по серверу (`user-contract/work-prompt.md`); перечень «что умеет система для этого сервера» в отказе `no_template` [K §2.2] подразумевает, что он известен на стороне агента.

## Данные

Документ контекста стенда M, запрос, эталонный адресат и содержание задачи, рубрика judge.
