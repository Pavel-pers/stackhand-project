## Вход

Вариант A — «какие базы 1С сейчас на сервере 1С?».

Вариант B — «какие базы данных есть в PostgreSQL на сервере 1С?». Ответ агента в тест не входит — проверяются выбор сервера и запрос агенту (prompt тулзы `delegate`).

## Ожидаемое поведение

- `delegate`, адресат — srv-1c, в обоих вариантах.
- Запрос агенту: проверить на сервере сейчас — A: список информационных баз кластера 1С; B: список баз в PostgreSQL; допустимо передать, что по описанию ожидаются Buh и ZUP (buh, zup) — как подсказку для сравнения.
- Ошибки: `answer-user` «Buh и ZUP» из краткого описания по тегу; `ask-user`.

## Эталон

- Тулза: `delegate`; `delegate_to`: srv-1c; момент — «сейчас».

## Метрики

- Rule-based: `orch-agent-choice` (`delegate_to` совпадает с эталоном), `orch-no-delegation` (ожидается `delegated`, не `answered`).
- LLM-judge: `judge-orch-task` — запрос агенту (prompt тулзы `delegate`) полный: сервер, что узнать, период или момент, параметры из запроса пользователя; без команд; без выдуманных путей и фактов. Засчитан при всех критериях.
