# orchestrator/answered/03 — «расскажи мне про сервер с 1С»

## Сценарий

Пункт плана «Server info» на уровне узла. Пользователь просит рассказать про сервер; оркестратор отвечает своим кратким описанием, не обращаясь к агенту, и не придумывает подробностей, которых у него нет: полное описание лежит у агента [UC-04].

## Контекст оркестратора

Документ контекста стенда M (ООО «Тестовая компания», оптовая торговля: офис, склад, сайт). Четыре сервера добавлены через форму 2026-10-08; у оркестратора по каждому — ip, теги и краткое описание из подтверждённого JSON, полного описания нет [UC-04]. Название сервера в документе контекста — `[предл.]`; в тестах это имя хоста.

| Название | ip | Теги | Краткое описание |
|---|---|---|---|
| web-01 | 10.0.1.11 | host, web/nginx, db/mysql, unsupported:provider-hv | Публичный сайт компании на VPS у хостинг-провайдера: nginx, PHP, MariaDB; раз в час забирает прайс из 1С |
| srv-1c | 10.0.1.12 | host, 1c/cluster, db/pg, web/apache | Сервер 1С: Бухгалтерия и ЗУП на PostgreSQL, около 12 пользователей; публикует данные 1С для обмена с сайтом; ночной бэкап баз |
| acc-01 | 10.0.1.13 | host, docker | Микросервисы бухгалтерии в Docker: сверка с контрагентами и распознавание первичных документов на GPU; redis и postgres в контейнерах |
| gw-01 | 10.0.1.1 | host | Шлюз офиса: WireGuard-туннели до склада и до VPS сайта; склад работает в 1С через туннель |

Плюс инструкции оркестратора и история текущей сессии [K §2.3]. Момент запроса — вторник 2026-10-27, 10:00 (+03:00), если в тесте не сказано иное.

## Вход

Запрос пользователя: «расскажи мне про сервер с 1С». Агент в тесте не участвует — проверяется только оркестратор.

## Ожидаемое поведение

- Класс `answered`, делегирования нет.
- srv-1c, 10.0.1.12: 1С с базами Бухгалтерия и ЗУП на PostgreSQL, около 12 пользователей; публикует данные 1С для обмена с сайтом; ночной бэкап баз. Уместно: сайт забирает из 1С прайс раз в час; склад работает в 1С через туннель шлюза.
- Технических подробностей сверх контекста нет; допустимо предложить узнать подробности у сервера (диски, нагрузка, сеансы).
- Ошибки: делегирование; версия PostgreSQL или платформы 1С, порты, тома, имя франчайзи — их нет в кратком описании (они только в полном описании у агента); точное время бэкапа.

## Эталон

- Класс: `answered`; факты — краткое описание и теги srv-1c, связи из описаний web-01 и gw-01.

## Метрики

- Rule-based: `orch-no-delegation`.
- LLM-judge: `judge-orch-arch` — только факты из документа контекста; ничего не выдумано; вопрос закрыт.

## Основания

[UC-04], [UC-12], [K §2.2] «Архитектурный вопрос». Не обсуждалось: запрос «расскажи всё про srv-1c» при полном описании у агента (`user-contract/architecture-question.md`).

## Данные

Документ контекста стенда M, запрос, рубрика judge.
