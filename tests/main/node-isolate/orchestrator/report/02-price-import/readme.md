## Вход

Транскрипт сессии (оркестратор перезапущен с ним [AR-28]):

- Пользователь: «прайс на сайте вчерашний — выгрузка из 1С отработала?»
- Оркестратор: `delegate(web-01, «Задание импорта прайса из 1С: последний успешный запуск, результаты запусков со вчерашнего дня, ошибки»)`
- Агент: `answer` (`executed`; вызвана `host.sched_jobs`): по журналу заданий планировщика, проверено 2026-10-27 10:00:40, задание www-data `15 * * * * /opt/site/bin/import_price.sh`.

- Последний успешный запуск — 2026-10-26 17:15:02, код 0, 2 с.
- С 2026-10-26 18:15 по 2026-10-27 09:15 — 16 запусков подряд с кодом 1, каждый ≈ 30 с.
- Хвост вывода задания: «curl: (28) Failed to connect to 10.0.1.12 port 8080 after 30001 ms: Connection timed out».

## Ожидаемое поведение

- Сказано: нет, не отработала — последний успешный импорт 26 октября в 17:15; с 18:15 все 16 запусков завершились ошибкой; сайт не может подключиться к srv-1c на порт 8080 (таймаут).
- Вывод «прайс не обновлялся с 26.10 17:15» сделан; что именно сломалось на стороне srv-1c или туннеля — не утверждается; допустимо предложить проверить доступность публикации 1С на srv-1c (второй `delegate` srv-1c — допустим механизмом [UC-26], но не требуется).
- Ошибки: «всё в порядке»; «1С упала» как факт; потерянное время последнего успеха; другое число неудачных запусков.

## Эталон

- Факты: последний успех 2026-10-26 17:15; 16 неудачных запусков с 18:15 по 09:15; код 1; таймаут подключения к 10.0.1.12:8080.
