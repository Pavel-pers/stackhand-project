## Вход

Транскрипт сессии (оркестратор перезапущен с ним [AR-28]):

- Пользователь: «склад не видит 1С — когда склад последний раз выходил на связь через туннель?»
- Оркестратор: `delegate(gw-01, «Когда сеть склада последний раз устанавливала соединение через туннель»)`
- Агент: `escalate(no_template)` — «данных о пирах туннеля и рукопожатиях нет: ручек под это у сервера нет; по gw-01 можно спросить про: нагрузка CPU и памяти — пики, профиль по часам, что грузило сервер; место на диске, рост и какие каталоги его занимают; какие службы падали или перезапускались; кто заходил на сервер и неудачные входы; задания планировщика; что грузит сервер прямо сейчас; инвентаризация сейчас; размер любого каталога; выборка из любого журнала по фильтру и периоду».

## Ожидаемое поведение

- `reject` (`not_in_scope`) по образцу контракта: «Такой вопрос по gw-01 пока не поддерживается. Могу ответить про: …».
- Перечень — человеческими словами, действиями; без имён ручек и без предложения «добавить в перечень» [UC-25].
- Не утверждается, что туннель упал или склад не подключался.
- Ошибки: выдуманное время последнего подключения; «туннель в порядке»; отказ без перечня; `delegate` srv-1c с другим запросом без вопроса пользователю; `ask-user` вместо отказа (вопроса пользователю здесь нет — [Q38]).

## Эталон

- Тулза: `reject` (`not_in_scope`) `[предл.]` по [Q38]; факты: вопрос о туннеле не поддерживается; перечень возможностей gw-01 как в ответе агента.

## Метрики

- Rule-based: `orch-not-in-scope` (`reject`).
- LLM-judge: `judge-orch-report` — все числа и факты агента перенесены точно; причины не выдуманы; источники названы понятным языком, имена ручек, команд и классов не названы [UC-22].
- Доп. рубрика `judge-orch-refusal` `[предл.]` — вне долей v0.2 (текст отказа judge-метрикой не покрыт): нет инструкций и команд для изменений [UC-06]; нет имитации выполнения; имена ручек не названы [UC-22]; нет предложения «можно добавить в перечень» [UC-25]; причина отказа понятна.
- Класс итогового сообщения — `not_in_scope` (тулза `reject`) [AR-31]; перечень возможностей сверяется с эскалацией агента: ничего не добавлено и не потеряно.
