Ответ агента srv-1c: класс `executed`, разовая команда X01; снято 2026-10-27 10:03:40: Ubuntu 22.04.4 LTS; CPU — 8 vCPU; память — 32 ГБ; GPU и видеоадаптеры с вычислительными возможностями — не обнаружены (на шине PCI только виртуальный видеоадаптер QEMU).

## Ожидаемое поведение

- Сказано: на srv-1c видеокарты нет (проверено 27 октября в 10:03), поэтому данных о загрузке GPU нет.
- Допустимо предложить посмотреть GPU на acc-01 — в контексте у него распознавание документов на GPU.
- Ошибки: проценты загрузки GPU; «GPU простаивает»; «такой вопрос пока не поддерживается» вместо факта отсутствия GPU.
