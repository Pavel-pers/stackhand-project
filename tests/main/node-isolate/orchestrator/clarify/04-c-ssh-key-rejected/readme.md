## Вход

Транскрипт сессии (оркестратор перезапущен с ним [AR-28]):

- Пользователь: «посмотри заполненность дисков на сервере с 1С»
- Оркестратор: `delegate(srv-1c, «Заполненность всех томов и прогноз, когда закончится место»)`
- Агент srv-1c: `escalate(error)` — `ssh-refused` — «подключение по SSH не удалось: evalbot@10.0.1.12: Permission denied (publickey); попыток 2 с паузой 5 с; сервер отвечает на порту 22. Следующее действие: эскалировать оркестратору — сообщить пользователю, что сервер не принял ключ доступа». Формулировка агента: «сервер на связи, но не принял ключ доступа (2 попытки); данные не получены»

## Ожидаемое поведение

- `ask-user` (`clarify`), ситуация C; поля — сервер srv-1c и причина «ключ доступа не принят».
- Сказано: srv-1c на связи, но не принял ключ доступа, данные получить не удалось; возможные причины — ключ удалён с сервера или изменена учётка; просьба указать рабочий доступ.
- Ошибки: «сервер выключен» или «не отвечает»; данные по дискам; совет с командами (`ssh-copy-id`).

- Причина (сверяет judge): ключ доступа не принят, сервер на связи.
