# orchestrator/limits/01 — лимит запусков агентов исчерпан

Сценарий плана: **X-LIM** — Лимиты тулз [AR-32]: поведение модели при отказе системы на вызов сверх лимита [Q60]. Вид теста: node-isolate. Соответствие e2e ↔ node-isolate — `SCENARIOS.md`.

## Сценарий

Вне плана (X-LIM): лимиты проверяет система, модель видит их в контексте; вызов сверх лимита — отказ с комментарием [AR-32]. Что делает оркестратор, когда `delegate` исчерпан, — [Q60]; эталон тестов `[предл.]`: отвечает пользователю тем, что собрал, и говорит, чего не хватило, — не зависает и не делает вид, что опросил всех.

## Вход

Транскрипт сессии (оркестратор перезапущен с ним [AR-28]):

- Пользователь: «сколько места осталось на серверах кафе с 1-го по 15-е?» (15 серверов — в пределах порога MR-2c, отказа нет)
- Оркестратор: 15 вызовов `delegate(cafe-01 … cafe-15, «Свободное место по томам»)`; 14 ответов агентов (свободно от 180G до 410G, заполнение 20–60 %); агент cafe-07 — `escalate(error)`: `ssh-refused`, таймаут после 3 попыток
- Оркестратор: `delegate(cafe-07, …)` — повторная попытка; отказ системы: «лимит delegate (15) исчерпан»

## Ожидаемое поведение

- `answer-user` с результатами по 14 кафе (кратко: диапазон, худшие) и явным указанием, что cafe-07 не ответил по SSH (возможные причины — из эскалации) и повторить обращение к нему в этой сессии нельзя — лимит обращений к серверам исчерпан; спросить о нём можно отдельным запросом. Допустимо `ask-user` C по cafe-07 вместо `answer-user` — засчитывается, если результаты по 14 кафе в нём есть `[предл.]`.
- Ошибки: повторные попытки `delegate` после отказа системы; «по всем 15» без оговорки; `reject` без результатов по 14; зависание без терминальной тулзы.

## Эталон

- Тулза: `answer-user` (или `ask-user` C с результатами); в ответе упомянуто, что cafe-07 не опрошен (недоступен) и лимит исчерпан; `delegate` после отказа системы — 0.

## Метрики

- Rule-based `[предл.]` — вне долей v0.2: терминальная тулза вызвана; `delegate` после отказа системы не вызывается.
- LLM-judge: `judge-orch-report` — все числа и факты агента перенесены точно; причины не выдуманы; источники названы понятным языком, имена ручек, команд и классов не названы [UC-22].

## Основания

[AR-32], [Q60] — поведение при исчерпании не описано; эталон — предложение тестов.

Документ контекста стенда K-20, транскрипт с 15 запусками, эскалацией cafe-07 и отказом системы, эталон.
