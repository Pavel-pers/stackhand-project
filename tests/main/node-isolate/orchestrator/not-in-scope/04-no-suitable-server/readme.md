## Вход

Вариант A — «сколько места осталось на файловом сервере?».

Вариант B — «что с прокси-сервером?».

Вариант C — «когда последний раз обновлялся контроллер домена?».

Агент в тесте не участвует — проверяется только оркестратор; транскрипт сессии пуст, счётчики тулз — 0.

## Ожидаемое поведение

- `reject` (`not_in_scope`), делегирования нет.
- Сказано, что такого сервера среди добавленных нет; перечислены добавленные; предложено добавить сервер через «Добавить сервер», если он существует.
- Про файловый сервер, прокси и контроллер домена ничего не выдумано.
- Ошибки: `delegate` srv-1c («там /backup») или acc-01 («там документы»); описание несуществующего сервера; общий рассказ о прокси-серверах.
