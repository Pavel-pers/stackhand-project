# main — рабочий запрос (оркестратор, локальный агент)

Тесты группы проверяют два вложенных цикла [AR-26], [AR-27]: оркестратор по краткому описанию, тегам и названию выбирает сервер [AR-23] и запускает агента тулзой `delegate` (≤ 15 на сессию); агент в цикле выбирает ручки (A — сводки по логам, B — one-shot [AR-24]; ≤ 20 на запуск), читает сводки или ошибки-enum [AR-25] и заканчивает `answer`/`escalate` (SSH — 2 попытки с паузой 5 с внутри ручки [AR-42]; «логгер перестал писать» — предупреждение вместе с результатом, design doc 4.1); оркестратор отвечает пользователю (`answer-user`, `ask-user` ≤ 7, `reject`; ответ + отказ ≤ 3) или запускает агента снова, в том числе другого сервера; после ответа пользователя перезапускается с транскриптом [AR-28]; пользователю всегда отвечает оркестратор [UC-27]; источники в ответе — понятным языком, имена ручек не называются [UC-22]; правило «один запрос — один сервер» снято [UC-26].

|---|---|---|
