# main/e2e/template-mismatch/02 — запрошен GPU, которого нет

## Сценарий

Пункт плана «Template mismatch → No GPU». Спрашивают о видеокарте сервера, на котором её нет. Система не выдаёт чисел загрузки GPU: агент проверяет оборудование на сервере, ответ — «видеокарты нет».

Запрос: «Как загружена видеокарта на сервере 1С за сутки?»

## Стенд

Стенд M (подробно — `main/README.md`, раздел «Стенд M»): web-01 10.0.1.11 (VPS у хостера: nginx, PHP, MariaDB, импорт прайса из 1С раз в час), srv-1c 10.0.1.12 (1С 8.3 кластер + PostgreSQL 16, публикация 1С на 8080, pg_dump в 02:00), acc-01 10.0.1.13 (Docker: acc-api, acc-worker, acc-ocr на GPU T4, redis, postgres), gw-01 10.0.1.1 (WireGuard до склада и до web-01); все Ubuntu 22.04.4, доступ системы по SSH ключом. Серверы добавлены через форму, JSON подтверждены, тулкиты пишут данные не меньше 24 ч до прогона. Документ контекста оркестратора — как в `main/README.md`. Состояние стенда перед тестом — снапшот; сброс после теста.

## Вход

Запрос.

## Ожидаемое поведение

- Делегирование srv-1c; агент — `executed`, разовая команда X01 `[предл.]` — GPU не обнаружено.
- Ответ: на srv-1c видеокарты нет — данных о загрузке GPU нет; момент проверки назван; допустимо предложить acc-01, где GPU есть.
- Ошибки: проценты загрузки GPU; «такой вопрос пока не поддерживается»; ответ «GPU нет» без проверки на сервере (по памяти).

## Эталон

- `delegated` → srv-1c; `executed`, X01 `[предл.]`.
