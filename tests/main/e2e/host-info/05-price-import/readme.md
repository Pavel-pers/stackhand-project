# main/e2e/host-info/05 — импорт прайса из 1С на сайт

## Сценарий

Наследник старого e2e/02. Оркестратор по контексту (сайт забирает прайс из 1С) выбирает web-01, а не srv-1c, хотя в запросе есть «1С»; агент читает планировщик и последние запуски задания импорта.

1. Засев: с вечера накануне прогона на gw-01 блокируется трафик web-01 → srv-1c:8080 — импорты падают по таймауту.
2. Запрос: «Прайс на сайте вчерашний — выгрузка из 1С отработала?»

## Стенд

Стенд M (подробно — `main/README.md`, раздел «Стенд M»): web-01 10.0.1.11 (VPS у хостера: nginx, PHP, MariaDB, импорт прайса из 1С раз в час), srv-1c 10.0.1.12 (1С 8.3 кластер + PostgreSQL 16, публикация 1С на 8080, pg_dump в 02:00), acc-01 10.0.1.13 (Docker: acc-api, acc-worker, acc-ocr на GPU T4, redis, postgres), gw-01 10.0.1.1 (WireGuard до склада и до web-01); все Ubuntu 22.04.4, доступ системы по SSH ключом. Серверы добавлены через форму, JSON подтверждены, тулкиты пишут данные не меньше 24 ч до прогона. Документ контекста оркестратора — как в `main/README.md`. Состояние стенда перед тестом — снапшот; сброс после теста.

Засев — шаг 1; блокировка снимается после теста.

## Вход

Запрос шага 2.

## Ожидаемое поведение

- Делегирование web-01; агент — `executed`, ручка `host.sched`.
- Отчёт: время последнего успешного запуска и число неудачных запусков с кодами — как в журнале; текст ошибки подключения из вывода задания (если он есть в возврате); вывод «прайс не обновлялся с …»; причина сверх факта не утверждается.
- Ошибки: делегирование srv-1c; «всё в порядке»; «1С упала» как факт; инструкция снять блокировку.

## Эталон

- `delegated` → web-01; `executed`, `host.sched`.

## Метрики

- Rule-based: `orch-agent-choice`, `local-template-choice`, `e2e-expected-state` (rule-based по журналу): классы узлов, `delegate_to`, шаблон и аргументы — как в эталоне; число делегаций — как в эталоне; состояние стенда после прогона не изменилось — система только читает [UC-06].
- LLM-judge: `judge-orch-report` — числа и факты в ответе пользователю совпадают с возвратом шаблона в журнале прогона; причины не выдуманы; период или момент назван; внутренние имена не упомянуты.

## Основания

[UC-04], [UC-08]; критерий «причины не выдуманы» [M].

## Данные

Живой стенд M, запрос, эталонные классы, адресат и шаблон, рубрика judge. Фактические числа берутся из журнала прогона (возврат шаблона), не из этого описания.
