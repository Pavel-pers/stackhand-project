# main/e2e/not-in-scope-local/01 — у агента нет логов под вопрос

## Сценарий

Пункт плана «Not in scope local → No toolkit logs». Оркестратор верно отправляет вопрос о туннеле шлюзу gw-01, но у шлюза нет тулкита для WireGuard: ни ручки, ни разовой команды под вопрос. Агент отвечает `no_template`, оркестратор — отказом с перечнем того, что умеет по gw-01.

Запрос: «Склад не видит 1С — когда склад последний раз выходил на связь через туннель?»

## Стенд

Стенд M (подробно — `main/README.md`, раздел «Стенд M»): web-01 10.0.1.11 (VPS у хостера: nginx, PHP, MariaDB, импорт прайса из 1С раз в час), srv-1c 10.0.1.12 (1С 8.3 кластер + PostgreSQL 16, публикация 1С на 8080, pg_dump в 02:00), acc-01 10.0.1.13 (Docker: acc-api, acc-worker, acc-ocr на GPU T4, redis, postgres), gw-01 10.0.1.1 (WireGuard до склада и до web-01); все Ubuntu 22.04.4, доступ системы по SSH ключом. Серверы добавлены через форму, JSON подтверждены, тулкиты пишут данные не меньше 24 ч до прогона. Документ контекста оркестратора — как в `main/README.md`. Состояние стенда перед тестом — снапшот; сброс после теста.

## Вход

Запрос.

## Ожидаемое поведение

- Делегирование gw-01; агент — `no_template` с перечнем возможностей по gw-01.
- Отказ по образцу контракта: «Такой вопрос по gw-01 пока не поддерживается. Могу ответить про: … Можно добавить в перечень поддерживаемых».
- Не утверждается, что туннель упал или склад не подключался; на gw-01 ничего не выполнено.
- Ошибки: делегирование srv-1c; выдуманное время подключения; «выборка журнала» как ответ о рукопожатиях; `wrong_addressee`.

## Эталон

- `delegated` → gw-01; локальный агент — `no_template`; шаблонов не выполнено.

## Метрики

- Rule-based: `orch-agent-choice`, `local-no-template`, `e2e-expected-state` (rule-based по журналу): классы узлов, `delegate_to`, шаблон и аргументы — как в эталоне; число делегаций — как в эталоне; состояние стенда после прогона не изменилось — система только читает [UC-06].
- LLM-judge: `judge-orch-report` (без критерия периода); доп. рубрика `judge-orch-refusal` `[предл.]` — без инструкций и команд для изменений, без имитации выполнения, без внутренних имён, причина понятна.
